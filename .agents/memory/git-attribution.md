name: Project Git attribution
description: The creator requires project commits attributed to their existing Git identity, not Replit Agent.
---

Use the creator's existing Git identity for project commits, not the generic
Replit Agent identity. Obtain the exact identity from existing creator-authored
commits rather than recording personal details here.

**Why:** The user explicitly requested that all project commits use their identity.

**How to apply:** Check repository-local Git configuration and actual commit
metadata. Automated checkpoint commits may override local configuration; do not
promise their attribution is controlled by Git settings alone. Obtain informed
consent before rewriting existing history or force-pushing.
